# Проверка прототипа

## Выбор модели — 4 ноября 2026

- В настройках доступны два варианта с подписями «20В — Лучшее качество» и «10B Лучшее соотношение скорость - качество».
- Для нового пользователя выбрана 20В. Переключение на 10B сохраняется после перезагрузки страницы; проверено в браузере.
- В первом запуске отображаются выбранная модель и размер: GigaChat 20B — около 12,5 ГБ, GigaChat 3.1 10B — около 6,5 ГБ. При смене модели завершённая демонстрация загрузки снова требует этап модели.
- Проверено переключение радиокнопок стрелками клавиатуры и оформление в светлой/тёмной теме; ошибок страницы в консоли нет.
- Отдельно проверено восстановление сохранённых идентификаторов и прежнего значения GigaChat 3.1 Lightning, а также безопасный выбор 20В для неизвестного/устаревшего варианта Qwen.
- Синтаксис изменённого JavaScript и локальные ресурсы проверены. Снимки находятся в `previews/model-settings-light.jpg` и `previews/model-settings-dark.jpg`.
- Проверка и переключение настоящих моделей не добавлялись: это изменение HTML-прототипа, исследовательские движки остаются отдельными.

## Первоначальная проверка

Проверено 3 ноября 2026 года в браузере на Windows.

- Синтаксис всех четырёх файлов JavaScript проверен средствами Node.js.
- Проверены локальные ссылки HTML на страницы, стили, скрипты и материалы: отсутствующих файлов нет.
- В редакторе проверены принятие одной правки и всех правок, сдвиг позиций после замены, отмена, отдельный режим стиля, добавление и удаление слова из словаря.
- В отдельном тексте с эмодзи и двумя одинаковыми ошибочными фразами замены применились к нужным фрагментам.
- Изменение текста во время проверки снимает подсказки; результат для предыдущей версии не появляется.
- Проверены диалог замены черновика примером, демонстрационный прогресс первого запуска, показ ошибки и повторная попытка.
- Проверены три варианта знака и переключение светлой и тёмной темы.
- В тёмной теме текст всех отмеченных ошибок имеет светлый цвет `#EBDBB2`; стандартный чёрный цвет элемента `mark` явно переопределён.
- При фактическом размере области страницы 1148 × 645 сайт помещается без прокрутки: высота содержимого 645, ширина 1148.
- На узком экране 328 × 709 сайт и приложение используют вертикальную прокрутку; горизонтального переполнения после корректировки заголовка нет.
- В проверенных страницах не обнаружены ошибки JavaScript в консоли.
- Отключение анимаций через `prefers-reduced-motion` предусмотрено в CSS; системная настройка в ходе проверки не менялась.

Снимки находятся в `previews`. Это проверка HTML-прототипа. Установка Ollama, загрузка модели, качество русскоязычной корректуры и работа настоящего приложения на Windows/macOS/Linux не проверялись.
