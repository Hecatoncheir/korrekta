# Дизайн «Корректы»

Публичный сайт, галерея скриншотов Flutter-приложения и материалы фирменного стиля. Настольное приложение реализовано на Flutter и Dart; сайт не выполняет проверку текста.

## Открыть

Публичный просмотр на GitHub Pages:

- [Одностраничный сайт](https://hecatoncheir.github.io/korrekta/).
- [Галерея приложения](https://hecatoncheir.github.io/korrekta/gallery.html).
- [Логотипы и иконки](https://hecatoncheir.github.io/korrekta/brand.html).

- `dist/index.html` — одностраничный сайт.
- `dist/gallery.html` — шесть скриншотов с примерами, навигацией с клавиатуры и увеличением.
- `dist/app.html` — совместимый переход со старого адреса в галерею; прототип больше не показывается.
- `dist/brand.html` — знак, три варианта, иконки, шрифты и палитра.

Можно открыть файлы напрямую. Для надёжной работы значков SVG и буфера обмена рекомендуется локальный HTTP-сервер:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Затем открыть `http://127.0.0.1:4173`. Шрифты и снимки включены в проект; внешних библиотек нет. Галерея работает без интернета после загрузки файлов. Скачивание установщиков и обновление ссылок через публичный GitHub API требуют сети; при недоступном API остаются прямые ссылки на проверенный v0.1.9. Для пользователей приложения эта команда не требуется.

Снимки редактора, перевода и настроек получены из Flutter-интерфейса на синтетических примерах через `app/tool/render_preview_test.dart`, генерации — через `app/tool/render_site_gallery_test.dart`; они не содержат пользовательских черновиков. Генерация доступна в настольном приложении начиная с v0.1.8. Архивные `app.js`/`app.css` сохранены как материалы прежнего прототипа, публичные страницы их не подключают.

## Направление

Палитра [Gruvbox](https://github.com/morhetz/gruvbox): тёплая бумага и угольный фон, оливковый акцент, мягкие формы. Базовые цвета сохранены из оригинала; полупрозрачные заливки ошибок и подсказок получены смешиванием акцента с фоном. Светлая тема: `#FBF1C7`, `#F9F5D7`, `#3C3836`, `#79740E`. Тёмная: `#282828`, `#32302F`, `#EBDBB2`, `#B8BB26`. Основной знак — буква «к» с росчерком корректора. Точка завершает название и присутствует в иконке. Дополнительные варианты — кавычки и чернильная капля.

Nunito используется для названия и заголовков, Nunito Sans — для интерфейса и редактируемого текста, JetBrains Mono — для коротких меток и чисел. Лицензии шрифтов находятся в `dist/assets/fonts`.

## Что можно посмотреть

- Главная: обзор приложения, кнопка «Посмотреть» и прямые ссылки с иконками Windows, macOS и Linux.
- Галерея: шесть снимков с примерами. На экранах до 760 px — вертикальная лента изображений во всю ширину, с обычной прокруткой и подписями под каждым снимком; на широких — вкладки, стрелки и Home/End. Увеличение и закрытие по Escape доступны в обоих вариантах. Прямые ссылки вида `gallery.html#translation` открывают выбранный пример.
- Сайт использует только тёмную тему Gruvbox, без переключателя. Прежняя настройка темы в браузере не применяется. Галерея также показывает светлую тему самого настольного приложения — это пример его интерфейса, а не оформление сайта.
- Страница оформления: три варианта знака и скачивание материалов.
- Галерея работает без JavaScript как страница с первым снимком; прямые ссылки на установщики также остаются доступны. Анимации учитывают `prefers-reduced-motion`.

## Файлы

`styles.css` и `shared.js` — общие цвета, шрифты, значки, диалоги и тема. `showcase.css` — главная и галерея, `gallery.js` — примеры и клавиатура, `site.js` — обновление ссылок на установщики из опубликованных GitHub Releases с готовыми пакетами для трёх ОС. Предварительные выпуски учитываются, черновики и служебные выпуски компонентов исключаются. `brand.css` и `brand.js` — страница оформления. Зависимости и сборка не нужны.

## Публикация

GitHub Actions проверяет JavaScript и локальные ссылки, затем публикует `dist/` на GitHub Pages. Публикация запускается при изменениях сайта в `main`; её также можно запустить вручную. В сайт попадают только отобранные обезличенные скриншоты из `dist/assets/screenshots`; рабочие черновики, журналы и остальные файлы `work/` не публикуются.
