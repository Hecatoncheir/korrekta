# Корректа

Локальный помощник для проверки и улучшения русскоязычных текстов на Flutter и Dart для Windows, macOS и Linux.

Настольная версия реализована на Flutter и Dart в [app](app/README.md). Есть редактор, локальное сохранение, ручное принятие и отмена правок, личный словарь, локальные перевод и генерация, настоящая проверка с выбором GigaChat 20В или 10В. Для новых настроек по умолчанию выбрана 10В; сохранённый выбор пользователя восстанавливается без замены. Интерфейс и настройки используют `flutter_bloc`; составные результаты — records, разбор данных — patterns.

Сборки Windows EXE, Linux RUN и macOS DMG готовит [CI](.github/workflows/desktop.yml). На `main` и в pull request выполняются проверки и сборки; тег `v*` публикует предварительный релиз с контрольными суммами после успешной сборки всех платформ. Версия установщика читается из `app/pubspec.yaml`.

Пошаговый план разработки и контрольные точки: [todo.md](todo.md).

Опубликован предварительный [v0.1.9 для Windows, macOS и Linux](https://github.com/Hecatoncheir/korrekta/releases/tag/v0.1.9): Enter в Vim Normal запускает проверку, генерацию или перевод текущего раздела. Удержание клавиши не повторяет запросы; доступны обычный Enter и Enter цифровой клавиатуры. Все задания релизного CI завершились успешно; файлы проверены по SHA-256.

## Исследование моделей

[Первое сравнение GigaChat и Qwen, скорость и требования к компьютеру](benchmarks/results/2026-11-03/README.md).

Первые модели проверены на Windows с GPU и без него. Отчёты сохраняют результаты своих исторических конфигураций; актуальные проверки настольного приложения приведены ниже.

Подготовлен [общий локальный режим с выбором по ролям источников](benchmarks/ensemble-tuning/README.md): OpenCorpora, общий словарь, SymSpell, Hunspell, LanguageTool и GigaChat дополняют предложения друг друга. После сравнения семи схем на прежних данных [независимая проверка 140 новых текстов](benchmarks/results/2026-11-04/ensemble-tuning/README.md) дала 55/60 чистых исправлений и 0/80 изменений правильного текста; одна лишняя замена в ошибочном предложении остаётся. Ядро подключено во Flutter с выбором 20В/10В, общей защитой и ручным принятием. Подробности запуска и ограничения — в [инструкции приложения](app/README.md). Безошибочная автоматическая корректура любого текста не подтверждена.

[Исследовательский эталон качества сохранён](benchmarks/best-known.json). [Сравнение памяти 20B и 10B](benchmarks/results/2026-11-04/model-memory/README.md) и [ресурсные профили](benchmarks/resource-profiles.json) описывают прежние конфигурации. Затем в приложении исправлен ошибочный шаблон 10В: [повторные 320 случаев](benchmarks/results/2026-11-05/text-response-fix/README.md) дали по 54/60 чистых исправлений у обеих моделей, по 1/80 лишних изменений правильных текстов и ни одной потери размеченных имён/оформления. Ответы 10В со скобкой исчезли: 26 → 0. По решению пользователя 10В выбрана по умолчанию; окончательная языковая приёмка требует следующего независимого набора.

## Идея

Корректа помогает находить опечатки, грамматические и пунктуационные ошибки, показывает предложения по исправлению и позволяет принимать или отклонять каждую замену. Улучшение стиля и перефразирование планируются как отдельные режимы.

## Платформы и интерфейс

Приложение должно работать на Windows, macOS и Linux. Интерфейс — простой и русскоязычный. Для обычного использования не требуется вводить команды в терминале.

При запуске Корректа автоматически проверяет и готовит Ollama, выбранную GigaChat, Java, LanguageTool 6.8, Hunspell 1.7.5 и словари. Недостающие переносимые компоненты скачиваются и запускаются внутри приложения без внешних установщиков и терминала. Готовые компоненты используются повторно. Видны этап и прогресс; загрузку можно остановить и продолжить. Редактор доступен сразу, проверка и перевод — после готовности среды.

Подробности размещения файлов и проверки целостности — в [инструкции приложения](app/README.md#подготовка-компонентов). Полный первый запуск с моделью на чистой macOS/Linux остаётся отдельной проверкой M6.

Основной экран — поле текста, кнопка проверки и список исправлений. В настройках доступны состояние Ollama, запуск, выбор и загрузка модели, прогресс и повторная попытка при ошибке. Если локальный компонент недоступен, приложение предлагает восстановить его работу.

## Архитектура

- **Flutter** — редактор, подчёркивание ошибок и карточки исправлений.
- **Dart** — правила типографики, словарь исключений, проверка предложенных замен и хранение настроек.
- **OpenCorpora + общий словарь** — распознавание известных словоформ; **SymSpell и Hunspell** — варианты исправления опечаток.
- **LanguageTool** — локальные правила орфографии, грамматики и пунктуации.
- **Ollama** — локальный запуск языковой модели и HTTP API для приложения.
- **GigaChat 20B-A3B-instruct-v1.5 Q4_K_M** — исследуемый источник дополнительных контекстных исправлений.

Предложения объединяются на одном снимке текста с общей защитой имён и оформления. Спорные замены доступны для просмотра и ручного выбора. Проверенный закрытый выбор GigaChat не используется как общий фильтр всех движков: на наших наборах он часто отклонял полезные правки. Словари, Hunspell и LanguageTool включены в автоматическую подготовку при первом запуске.

Интерфейс и прикладная логика пишутся на Dart. Ollama работает отдельным компонентом. При использовании локальной модели проверка должна выполняться на устройстве без отправки текста в облако.

Выбор модели предварительный: качество русскоязычной корректуры, скорость и потребление памяти необходимо измерить до принятия окончательного решения.

## Оценка качества

Проверочный набор должен включать тексты с ошибками и правильные тексты, разговорную речь, имена и технические термины. Основные показатели: правильность предложений, пропущенные ошибки, лишние изменения и задержка ответа.

Дообучение модели рассматривается после оценки готовых моделей.
