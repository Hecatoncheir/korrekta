Предварительная настольная версия Корректы для Windows, macOS и Linux.

Изменения версии 0.1.7:

- Исправлено подключение GigaChat 10В: теперь Ollama применяет собственный шаблон этой модели через `/api/chat`. Раньше использовался шаблон 20В, из-за чего часть ответов содержала только `{"text":"{"}`.
- 10В выбрана по умолчанию для новых настроек. Сохранённый выбор пользователя восстанавливается без замены; 20В остаётся доступной в настройках.
- Пустые и сильно обрезанные ответы не выдаются за успешную проверку. В подсказках появляется «Проверка неполная», исходник сохраняется, предложения словарей и LanguageTool доступны. Успешный повтор убирает предупреждение.
- Предупреждение доступно и в узком окне. Проверены сохранение ранее выбранной модели, переключение моделей, повтор проверки и горячая перезагрузка интерфейса.

Повторены 320 случаев через настоящее Windows-приложение. У 10В чистые исправления выросли с 47/60 до 54/60, ответы со скобкой исчезли: 26 → 0. Итоговые тексты 10В и 20В совпали; потерь размеченных имён и оформления нет. У обеих остаётся одна лишняя правка из 80 правильных текстов и шесть пропусков. Это повторная проверка на известном наборе, а не гарантия безошибочной корректуры любого текста.

Подробности: [результаты и журналы проверки](https://github.com/Hecatoncheir/korrekta/blob/v0.1.7/benchmarks/results/2026-11-05/text-response-fix/README.md).

Автоматическая подготовка компонентов, локальный перевод, Vim mode, личный словарь, сохранение черновиков и окна, обновление установленной копии с проверкой SHA-256 сохранены. После подготовки обработка текста выполняется локально.

Для первоначальной подготовки нужны интернет, свободное место и достаточная память для выбранной модели. Веса скачиваются отдельно при запуске и в установщики не входят. Готовые компоненты и существующая папка весов Ollama используются повторно. После подготовки обработка текста выполняется локально. Пока проверяются фрагменты до 1200 знаков, переводятся — до 3000; длинный текст не обрезается автоматически.

Windows: установщик `.exe`, x64. Linux: установщик `.run`, x64, Ubuntu 22.04 или новее с GTK3; файл нужно разрешить исполнять и открыть. macOS: `.dmg`, Intel и Apple Silicon. Сборки пока не подписаны сертификатом разработчика и не нотарифицированы Apple. Автоматическая установка и запуск компонентов без весов GigaChat проверены в CI на Windows, Linux и macOS Apple Silicon. Полный сценарий с моделью проверен на текущем Windows-компьютере; ручная проверка приложения на чистых macOS/Linux остаётся задачей M6.

Исходный текст не меняется без принятия подсказки. Безошибочная корректура любого текста не гарантируется. Проверить целостность загрузки можно по SHA256SUMS.
