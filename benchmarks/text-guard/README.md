# Защита текста на Dart

Версия `text-guard-v1` защищает исходник перед применением ответа модели. Это переиспользуемое ядро для будущего Flutter-приложения и действующего исследовательского CLI; интерфейс Flutter пока не создан. [Протокол](protocol-v1.json), [результаты](../results/2026-11-04/text-guard/README.md).

## Контракт

`guardText` получает только снимок исходного текста, предложенный моделью текст и необязательный личный словарь. Эталоны, категории и разметка `protected` ему недоступны. Индексы правок — UTF-16, как в Dart. `applyTo` проверяет полное совпадение снимка: результат нельзя применить после ввода нового символа без повторной проверки.

Автоматически защищаются слова с заглавными буквами и латиницей, пробелы, переносы, табуляция, цитаты, технические строки, код, поддержанные конструкции Markdown, эмодзи и комбинируемые символы. Имена определяются консервативной эвристикой: первое слово предложения тоже защищено. Для неизвестных имён со строчной буквы нужен личный словарь; гарантии распознавания всех имён нет. Словарь учитывает регистр независимо и проверяет границы полного слова. Склонения автоматически не добавляются.

После Unicode diff разрешены небольшие замены одного слова: не более двух операций редактирования и 40% длины. Внутри текста разрешены запятые, двоеточия и точки с запятой. Изменение пробелов, новые слова, перестановки, крупные замены, конечная пунктуация и чистые замены е/ё отклоняются. Цитаты заморожены целиком. Политика намеренно пропускает часть настоящих ошибок, включая ошибки внутри имён и цитат; исправление раскладки требует отдельного механизма.

Перед выдачей результата проверяется дословное сохранение вычисленных защищённых диапазонов с учётом сдвигов. Некорректный UTF-16, входы длиннее 4000 Unicode-символов и diff свыше 4 млн ячеек возвращают исходник с причиной отказа. Статус `all_changes_blocked` означает отклонённые предложения, а не отсутствие ошибок. Фильтр не подтверждает языковую или смысловую правильность оставшихся замен.

```dart
import 'package:korrekta_model_benchmark/text_guard.dart';

final result = guardText(
  'Аурика проверяит письмо.',
  'Аурица проверяет письмо.',
  names: ['Аурика'],
);
final corrected = result.applyTo('Аурика проверяит письмо.');
// Аурика проверяет письмо.
```

## Повторная оценка без модели

Из `tools/model_benchmark` с уже установленными зависимостями:

```powershell
dart run bin/protect_results.dart --input ../../benchmarks/results/2026-11-03/giga20-gfusion/gigachat20-preservation.jsonl --output work/preservation-guarded.jsonl
dart run bin/compare_texts.dart ../../benchmarks/results/2026-11-03/giga20-gfusion/gigachat20-preservation.jsonl work/preservation-guarded.jsonl
```

Выходной файл должен быть новым. Исходный ответ сохраняется в `content` и `unfiltered_output`; `output` содержит принятый результат. Записываются диапазоны защиты, принятые и отклонённые правки, причины и отдельное время фильтра. Для личного словаря добавьте `--names ../../benchmarks/text-guard/personal-names.json`. Этот пример словаря — явная пользовательская настройка, а не автоматическое распознавание.

Для проверки дословных фрагментов из корня проекта:

```powershell
python -X utf8 benchmarks/preservation/check_retention.py --data benchmarks/preservation/cases-v1.jsonl --output tools/model_benchmark/work/retention-guarded.json benchmarks/results/2026-11-03/giga20-gfusion/gigachat20-preservation.jsonl tools/model_benchmark/work/preservation-guarded.jsonl
python -X utf8 benchmarks/text-guard/summarize.py --check
```

Вторая команда проверяет замороженные суммы кода, промпта, наборов и исходных ответов, структуру нового набора и соответствие опубликованной сводки сохранённым оценкам. Она не пересчитывает ответы модели; сравнения воспроизводятся отдельными Dart-командами выше. Новые библиотеки для повторной оценки не нужны.

## Новый запуск GigaChat 20B

Используются уже скачанные на E: веса, отдельный Ollama на `127.0.0.1:11435` и официальный шаблон, как в [исследовании GigaChat 20B](../giga20-gfusion/README.md). Из корня подготовьте новый выход:

```powershell
E:\korrekta\sage-venv\Scripts\python.exe -X utf8 benchmarks/giga20-gfusion/render_gigachat20.py --data benchmarks/text-guard/holdout-v1.jsonl --prompt benchmarks/gigachat-prompts/text-json.txt --output work/guard-holdout-rendered.jsonl
```

Из `tools/model_benchmark`:

```powershell
dart run bin/benchmark.dart --model hf.co/ai-sage/GigaChat-20B-A3B-instruct-v1.5-GGUF:Q4_K_M --endpoint http://127.0.0.1:11435 --raw --response-mode text-json --protect --data ../../work/guard-holdout-rendered.jsonl --prompt ../../benchmarks/gigachat-prompts/text-json.txt --split test --output work/guard-holdout-live.jsonl
```

Без `--protect` сохраняется прежний режим. Для парного сравнения до/после лучше один раз получить сырой ответ и обработать его `protect_results.dart`: модель тогда не генерирует два разных ответа. Живой режим `--protect` использует тот же фильтр. Измерение фильтра отдельно от модели сохраняется в обоих режимах.

Набор `holdout-v1.jsonl` содержит 20 новых пар: правильная фраза и фраза с ошибкой. Фразы и политика зафиксированы до новых запросов, после просмотра оценок ограничения не подбирались. Все основные результаты — без личного словаря. Словарь проверяется отдельным дополнительным профилем на тех же ответах. Набор небольшой и авторский; это проверка регрессий, а не внешний рейтинг русского языка.
