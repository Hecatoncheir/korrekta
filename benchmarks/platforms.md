# Границы первой версии и платформы

## Сценарий v0.1.0

Пользователь пишет или вставляет обычный текст, выбирает абзац и запускает проверку кнопкой. Подсказки показывают конкретный фрагмент, замену и короткое объяснение. Можно принять, отклонить и отменить замену. При редактировании текста старые подсказки снимаются. Черновик и словарь сохраняются локально.

Стиль и перефразирование — отдельные последующие режимы. Проверяемый текст обрабатывается на устройстве; загрузка программы и модели требует интернета.

## Начальные целевые платформы

| ОС | Архитектура | Основание и состояние |
| --- | --- | --- |
| Windows 10 22H2 / Windows 11 | x64 | Общая граница выбранного локального компонента и Flutter. Измерения моделей выполнены на Windows 11 Pro, сборка 26200. Приложение и его установщик ещё не проверялись. |
| macOS 14 и новее | arm64, Apple Silicon | Начальная цель по требованиям Ollama. Проверка на реальном Mac ещё требуется. |
| Ubuntu 24.04 LTS | x64 | Начальная цель Linux для проверки; практическая установка Ollama и пакета приложения ещё требуется. |

Это цели разработки, а не объявление о прошедшей приёмке. Поддержка Intel Mac, Windows ARM64, других дистрибутивов и архитектур Linux требует отдельного решения и проверки. Доступность устройств macOS и Linux для ручной приёмки нужно уточнить.

Версии для начала разработки закреплены в [toolchain.json](../toolchain.json): Flutter 3.47.9 stable и Dart 3.13.7. Установленный Flutter совпал с текущей веткой `stable` при проверке. Проверка инструмента сравнения в CI использует тот же Dart; сборки Flutter для трёх ОС добавляются в M2.
