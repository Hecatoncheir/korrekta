# Сохранение текста при корректуре

Новый авторский набор для отдельного вопроса M1: исправляет ли движок ошибку, сохраняя имена, эмодзи, оформление и технические фрагменты. Он создан после исследования v1, но до получения ответов на эти 120 текстов. Точных совпадений исходных текстов с первым набором нет. Параметры движков и эталоны после просмотра ответов не менялись.

Состав: **60 новых контекстов в двух вариантах** — правильном и с одной внесённой ошибкой, всего 120 текстов. Это 60 пар, а не 120 независимых контекстов. По десять пар с кавычками, именами, эмодзи, оформлением, техническими фрагментами и сочетаниями этих признаков. Целевые слабые места выбраны по предыдущему исследованию; набор не является внешней независимой лингвистической приёмкой или репрезентативным рейтингом русского языка.

Имена и названия считаются данными автора, даже если их нет в словаре. Ссылки, адреса, пути, идентификаторы и код сохраняются дословно. Отступы и двойные пробелы здесь намеренные. Короткие сообщения с эмодзи допустимы без конечной точки. Типографическая нормализация считается нарушением задачи сохранения; отдельный режим типографики мог бы иметь другой эталон.

## Воспроизведение

```powershell
python -X utf8 benchmarks/preservation/prepare_cases.py
```

Генератор проверяет уникальность текстов, отсутствие точных совпадений с первым набором, однозначность исправления и сохранность `protected` в эталоне. `cases-v1.jsonl` фиксируется в Git. SHA-256 по UTF-8/LF и параметры находятся в [protocol-v1.json](protocol-v1.json).

Для LanguageTool из `tools/model_benchmark`:

```powershell
dart run bin/languagetool.dart --data ../../benchmarks/preservation/cases-v1.jsonl --split test --output ../../work/preservation-lt.jsonl
```

Для SAGE из корня проекта:

```powershell
& E:\korrekta\sage-venv\Scripts\python.exe -X utf8 benchmarks/sage/run.py --data benchmarks/preservation/cases-v1.jsonl --split test --device cpu --output work/preservation-sage.jsonl
```

Связка запускается через `benchmarks/languagetool/pipeline.py`: сначала `prepare` для выхода LanguageTool, затем тот же вызов SAGE на промежуточном наборе, затем `merge` с исходным результатом LanguageTool. [Подробности](../languagetool/README.md). Первый вариант LanguageTool выбран без знания эталона; это оценка такой автоматической стратегии, а не максимального качества всех предложений при ручном выборе.

Для общей оценки используйте `compare_texts.dart` как в [инструкции SAGE](../sage/README.md). Отдельно проверьте защищённые фрагменты:

```powershell
python -X utf8 benchmarks/preservation/check_retention.py --data benchmarks/preservation/cases-v1.jsonl --output work/preservation-retention.json work/preservation-sage.jsonl work/preservation-lt.jsonl
```

`check_retention.py` проверяет совпадение полного набора идентификаторов, входного текста и эталона. Фрагмент считается сохранённым, если число его дословных вхождений в ответе совпадает с исходным. Перестановка неизменившегося фрагмента сама по себе этим счётчиком не обнаруживается; полное совпадение итогового текста с эталоном оценивается отдельно. Метрика «ошибка исправлена без лишних изменений» требует именно полного совпадения на ошибочном варианте пары.

## Проверка среды SAGE

После основного прогона выполнен дополнительный запуск на Transformers 4.57.6. Основная установка 5.22.1 не заменялась, PyTorch, веса, FP32 и CPU сохранены. Совместимые пакеты установлены через `pip --target E:\korrekta\sage-transformers4 transformers==4.57.6`, с кешем и временными файлами на E:. Список версий сохранён в результатах.

```powershell
$env:PYTHONPATH = 'E:\korrekta\sage-transformers4'
& E:\korrekta\sage-venv\Scripts\python.exe -X utf8 benchmarks/sage/run.py --data benchmarks/preservation/cases-v1.jsonl --split test --device cpu --output work/preservation-sage-transformers4.jsonl
Remove-Item Env:\PYTHONPATH
```

Эта проверка диагностическая: она не заменяет первоначальные результаты и не доказывает одинаковое поведение всех версий среды или других моделей SAGE. [Результаты и выводы](../results/2026-11-03/preservation/README.md).
